# Hyouka Zombie Survival 3D

Kotlin/libGDX Android 3D survival game.

Features:
- Touch movement and camera control.
- Non-weapon energy pulse ability.
- Zombie waves, health, energy, score and progression.
- Procedural low-poly environment for mobile performance.
- Landscape Android layout.

Build with JDK 17 and Gradle 8.9:
gradle :android:assembleDebug

GitHub Actions builds the debug APK on every push to main.

libGDX 1.14.2 is used for the 3D renderer and Android backend.
